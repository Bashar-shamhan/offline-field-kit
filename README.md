# Offline Field Kit — حقيبة الفحص الميداني دون اتصال

أداة مفتوحة المصدر تعمل بالكامل دون إنترنت، للفنيين والطلاب، لتوثيق الشبكة المحلية وفحص الأجهزة وتوليد تقرير فحص أمني مبسّط، ثم تصديره عند توفر الاتصال.

## ما تفعله النسخة الأولى (v0.1)
- تكتشف عنوان IP المحلي والشبكة والبوابة (Gateway) إن توفرت.
- تتحقق من الاتصال بالبوابة وبخادم DNS عام (8.8.8.8) — وتسجّل النتيجة، ولا تعتمد على الإنترنت لتعمل.
- تفحص مجموعة منافذ شائعة على الجهاز المحلي والبوابة (مثل 22، 80، 443) وتسجّل المفتوح منها فقط، دون أي فحص عدواني.
- تولّد تقريرين: `report.md` (قابل للقراءة) و `report.json` (قابل للمعالجة) داخل مجلد `output/`.

## التشغيل (لا حاجة لأي مكتبات خارجية — Python 3.10+ فقط)
```bash
python3 fieldkit.py
python3 fieldkit.py --output output
```

## ملاحظات أمنية مهمة
- الأداة مخصصة لفحص شبكتك أنت أو شبكة لديك إذن صريح بفحصها فقط.
- لا ترسل أي بيانات إلى أي خادم، ولا تجمع كلمات مرور أو بيانات شخصية.
- الفحص محدود بالمنافذ الشائعة وبمهلة قصيرة لكل منفذ، لتجنب إرباك الشبكة.
